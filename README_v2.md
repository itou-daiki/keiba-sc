# 🏇 競馬スクレイピング v2 - 82カラム完全対応版

## 📋 概要

JRAとNARの競馬データを**82カラム完全対応**でスクレイピングする新しいバージョンです。
過去成績（5走分）と血統情報を含む完全なデータセットを取得できます。

## 🆕 v2の主な改善点

### 1. **82カラム完全対応**
- 基本情報（26カラム）
- 過去成績（65カラム：past_1～past_5 × 13項目）
- 血統情報（3カラム：father, mother, bms）

### 2. **スマートな欠損チェック**
既存データを読み込み、以下をチェック：
- 基本情報（日付、会場、馬名など）
- 過去成績データの有無
- 血統情報の有無

**不完全なレースのみ再取得**するため、効率的です。

### 3. **メモリ効率化**
- 5レースごとにガベージコレクション
- Colab環境でも安定動作

### 4. **カラムずれ完全防止**
- `reindex`で82カラムを厳密に保証
- 追記時に既存ファイルのカラム順序に自動調整

## ⚙️ 動作の詳細

### 初回実行時
1. 指定期間の全レースを取得
2. 各馬の過去5走分の成績を取得
3. 各馬の血統情報を取得
4. 82カラムのCSVファイルを作成

### 2回目以降の実行
1. 既存データを読み込み
2. 各レースの完全性をチェック：
   - 基本情報が揃っているか
   - 過去成績（past_1_date）があるか
   - 血統情報（father）があるか
3. **不完全なレースのみ再取得**
4. 追記時にカラム順序を自動調整

### メモリ管理
- 5レースごとに`gc.collect()`実行
- 処理状況を定期的に表示
- Colab環境でも安定動作

## 📊 データ構造（82カラム）

### 基本情報（26カラム）
```
日付, 会場, レース番号, レース名, 重賞, コースタイプ, 距離, 回り, 天候, 馬場状態,
着順, 枠, 馬番, 馬名, 性齢, 斤量, 騎手, タイム, 着差, 人気, 単勝オッズ, 後3F,
厩舎, 馬体重(増減), race_id, horse_id
```

### 過去成績（65カラム）
past_1～past_5について、各13項目：
```
past_N_date, past_N_rank, past_N_time, past_N_run_style, past_N_race_name,
past_N_last_3f, past_N_horse_weight, past_N_jockey, past_N_condition,
past_N_odds, past_N_weather, past_N_distance, past_N_course_type
```

### 血統情報（3カラム）
```
father, mother, bms (母父)
```

## ⚠️ 注意事項

### 処理時間
- **過去成績と血統も取得するため、従来版より時間がかかります**
- 1レースあたり約15-20秒（馬が16頭の場合）
- 目安：100レース = 約30-40分

### レート制限
- 1.0-2.0秒のランダムディレイを自動設定
- サーバーへの負荷を考慮した設計

### エラーハンドリング
- 最大3回のリトライ
- 失敗したレースはログに記録
- 部分的な失敗でも継続実行

## 🔍 トラブルシューティング

### カラム数が82でない
```python
# 既存ファイルのカラム数を確認
import pandas as pd
df = pd.read_csv('database.csv', nrows=0)
print(f"現在のカラム数: {len(df.columns)}")
print(df.columns.tolist())
```

対処法：
1. 既存ファイルをバックアップ
2. 新しいファイル名で実行
3. または既存ファイルを削除して再実行

### メモリ不足
- 処理期間を短く（例：1ヶ月ずつ）
- Colab Proの利用を検討

### 過去成績が取得できない
- horse_idが正しいか確認
- ネットワーク接続を確認
- 時間をおいて再実行

## 📈 バックフィルについて

v2では**スクレイピング時に全データを取得**するため、バックフィルは基本的に不要です。

ただし、以下の場合は既存のバックフィルノートブックが使用できます：
- v1で取得したデータに過去成績・血統を追加したい
- 一部のレースのみデータが不完全な場合

## 🎯 推奨ワークフロー

1. **新規データ取得**
   - `Colab_JRA_Scraping_v2.ipynb` を使用
